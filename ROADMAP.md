# Roadmap Pembangunan Diskusi Hukum

## Fase 0 — Fondasi

- [ ] Tentukan domain final.
- [ ] Tentukan logo, warna, dan gaya visual.
- [ ] Buat akun sosial media komunitas.
- [ ] Buat pedoman editorial dan template artikel.
- [ ] Tentukan tiga pilar awal: hukum sehari-hari, digital & privasi, ketenagakerjaan & kontrak.
- [ ] Siapkan 12 artikel fondasi.
- [ ] Siapkan 10 istilah kamus hukum.
- [ ] Siapkan 3 toolkit/checklist.

## Fase 1 — MVP

- [ ] Setup repository dan environment.
- [ ] Setup database dan autentikasi admin.
- [ ] Buat design system dasar.
- [ ] Buat beranda.
- [ ] Buat daftar dan detail artikel.
- [ ] Buat kategori dan tag.
- [ ] Buat pencarian.
- [ ] Buat halaman tentang komunitas.
- [ ] Buat form usulkan topik.
- [ ] Buat dashboard admin artikel.
- [ ] SEO: metadata, sitemap, robots.txt, Open Graph.
- [ ] Uji mobile.
- [ ] Deploy MVP.

## Fase 2 — Konten dan Komunitas

- [ ] Kamus Hukum.
- [ ] Toolkit/Checklist.
- [ ] Profil dan pendaftaran kontributor.
- [ ] Agenda diskusi.
- [ ] Arsip materi komunitas.
- [ ] Newsletter.
- [ ] Statistik artikel populer.
- [ ] Form feedback artikel.

## Fase 3 — Interaksi dan Moderasi

- [ ] Komentar termoderasi.
- [ ] Notifikasi review kontributor.
- [ ] Bookmark artikel.
- [ ] Learning path.
- [ ] Report komentar.
- [ ] Riwayat perubahan artikel.

## Fase 4 — Produk Belajar

- [ ] Learning path Dasar Hukum Perdata, Hukum Konsumen, Hukum Digital.
- [ ] Kuis ringan per topik.
- [ ] Direktori lembaga bantuan hukum.
- [ ] Export toolkit ke PDF.
- [ ] Dashboard analitik konten.

## Checklist Rilis MVP

### Konten
- [ ] Minimal 12 artikel siap terbit.
- [ ] Minimal 8 artikel memiliki sumber resmi.
- [ ] Setiap artikel punya cover, ringkasan, kategori, tag.
- [ ] Halaman Tentang Komunitas selesai.
- [ ] Pedoman editorial tersedia.

### Teknis
- [ ] Domain dan HTTPS.
- [ ] SEO metadata, sitemap, robots.txt.
- [ ] Form usulkan topik berfungsi.
- [ ] Dashboard admin berfungsi.
- [ ] Backup database aktif.
- [ ] Analytics terpasang.

### Pengalaman
- [ ] Tampilan mobile rapi.
- [ ] Pencarian berfungsi.
- [ ] Artikel cepat dibuka.
- [ ] Tombol share berfungsi.
